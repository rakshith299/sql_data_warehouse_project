### **Dataset Documentation**

**Format**: CSV
--------------------------------------------------------------------------------------------------------------------

**1. Source CRM**

| Filename | Description | 
|---|---| 
| cust_info | Contains information on customers such as name, gender, and marital status |
| prd_info | Contains information on products such as name, cost, and the start and end date of that particular cost |
| sales_details | Contains information on sales such as product_id, customer_id, cost of product, shipping details |

-----------------------------------------------------------------------------------------------------------------------

**2. Source ERP** 

| Filename | Description | 
|---|---| 
| cust_az12 | Contains additional information on customers such as their birthdate |
| loc_a101 | Contains additional information on customers such as their location |
| px_cat_g1v2 | Contains additional information on products such as their category and subcategory |

-----------------------------------------------------------------------------------------------------------------------
